# java-lotto-precourse

## 구매 금액 입력
- 사용자의 로또 구매 금액을 받는다.
  - 금액은 1,000 단위로 나눠떨어져야 하며, 1,000원 미만일 수 없다.
  - [ ] 천원당 로또 하나를 생성한다. 생성된 로또는 정렬되어야한다.
  - 위 과정에서 에러가 발생하면 처음부터 다시 동작한다.

- 당첨 번호를 받는다.
  - 당첨 번호는 `,`로 구분된 6개의 숫자를 입력하여 처리한다.
  - 각 숫자의 앞뒤에 포함된 공백은 `trim()`을 호출하여 처리한다.
  - 위 과정에서 에러가 발생하면 처음부터 다시 동작한다.

- 보너스 번호를 입력한다.
  - 당첨 번호는 반드시 양의 정수이다.
  - 위 과정에서 에러가 발생하면 처음부터 다시 동작한다.
  - 구매한 로또의 수와 구매된 로또 번호를 출력한다.

- 예외 상황
  - 입력을 받는 도중 예외가 발생하면 입력 문구도 같이 출력한다.
  - [ERROR] 로 시작해야한다.
